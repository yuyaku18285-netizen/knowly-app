# KNOWLY

忘れる直前に問題を出す、一問一答の学習アプリです。スマホのブラウザで動きます。

アプリ: https://（ユーザー名）.github.io/knowly-app/

## 何ができるか

- 中学社会(歴史・公民)の問題が1335問入っています。
- 「4択」と「思い出す(答えを見て自分で○×をつける)」の2つのやり方があります。
- 1回10問。次の順で出題します。
  1. まだ解いていない問題
  2. 間違えた問題(もう一度)
  3. 忘れる直前の問題(予想される正解率が下がってきたもの)
- 範囲は「教科 → 単元」の順にえらべます。えらぶとそのまま出題がはじまります。
- ホーム画面に追加すると、アプリのように開けます。電波がなくても使えます。

## 出題のしくみ

問題ごとに、「いま思い出せる確率」を次の式で予想しています。

```
p = 下限 + (1 - 下限) × exp( -経過日数 / (S × k) )
```

- `S`: その問題の覚えやすさ(日)。正解すると伸び、間違えると縮みます。
- `k`: その人の忘れやすさ係数。解答のたびに少しずつ調整されます。
- `下限`: 当てずっぽうでも当たる確率(思い出す 0.2 / 4択 0.25)。

pが目標(0.99)を下回った問題が、「忘れる直前」の問題として出ます。

## データについて

- 記録は、使っている端末(ブラウザ)の中にだけ保存されます。サーバーには送りません。
- IDは端末ごとのランダムな文字列で、名前とは結びついていません。
- 設定の「バックアップを保存する」で、記録をファイルに保存して復元できます。
- 設定の「CSVを書き出す」で、解答の記録(生徒ID・問題ID・解答日時・正誤・解答秒数・挑戦回数)を分析用に書き出せます。

## 分析ノートブック(notebooks/)

出題方式を比べるために、Python(Jupyter)で書いた分析です。

| ファイル | 内容 |
|---|---|
| knowly_01_simulation.ipynb | 架空の生徒で、ランダム出題とSM-2を比べる |
| knowly_02_personalized.ipynb | 生徒ごとの予測をつかう出題方式を作って、公平に比べる |
| knowly_03_analysis.ipynb | ②が作った解答の記録を、pandasで集計・可視化する |

**注意**: ノートブックで使っているのは、仮のルールで作った**架空のデータ**です。結果は「仕組みが動くことの確認」で、「効果の証明」ではありません。実際の効果は、使ってもらったデータで確かめる予定です。

動かし方:

```
pip install -r requirements.txt
cd notebooks
jupyter notebook   # またはVS Codeで開く
```

①→②→③の順に、「すべて実行」を押してください。②が `notebooks/data/` に記録のファイルを作り、③がそれを読みます。

## フォルダ
